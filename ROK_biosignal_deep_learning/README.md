# ROK_biosignal_deep_learning

CNN and graph convolutional network (GCN) experiments for biosignal classification.

## Usage

Install the demo dependency with `pip install -r requirements.txt` and run `python demo.py` for a synthetic CNN forward pass.

The `notebooks/` folder contains historical experimental workflows. The CNN notebook requires original data and additional setup. The GCN notebook requires TensorFlow 1.x, external graph convolution libraries and the original data layout; it is not standalone. No experimental data are included.
